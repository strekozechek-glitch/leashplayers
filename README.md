# GuardianAntiCheat (Paper / Leaf 26.2)

Продвинутый античит и инспектор клиентов/модов для серверов **Minecraft 26.2** (Paper / Purpur / Leaf).

## Возможности

1. **Client Brand Detector:**
   * Автоматический перехват входящего канала `minecraft:brand` и `fml:handshake`.
   * Определение типа клиента игрока: Vanilla, Fabric, Forge, NeoForge, Feather, Lunar, Badlion, а также сигнатур взломанных клиентов (Meteor, Wurst, LiquidBounce и др.).
2. **Anti-Spoofer Engine:**
   * Проверка и валидация подписи сетевых пакетов хэндшейка при подключении.
   * Блокировка подделки брендов и клиентских каналов.
3. **Client Inspection Command:**
   * `/guardian info <ник>` — выводит детальную диагностику подключенного клиента, используемый бренд, сетевой статус и валидацию анти-спуфера.
4. **Легковесность:**
   * Скомпилирован в чистый JVM-байткод, нулевая нагрузка на серверный тик (20 TPS).

---

## Установка

1. Поместите файл `GuardianAntiCheat-26.2.jar` в папку `plugins/` вашего сервера Paper / Leaf 26.2.
2. Перезапустите сервер или выполните `/reload confirm`.
3. Готово! Плагин начнет логировать клиентов в консоль и чат администраторам.
